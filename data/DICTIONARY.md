# Data dictionary

Every table below is generated by `analysis/` code. Nothing is hand-edited.

## `data/raw/`
- `cache/` — verbatim E-utilities responses, keyed by URL hash. Immutable; deleting a file only forces a re-fetch.
- `anchor_candidates.json` — anchor-set resolution, pass 1 (`analysis/01_anchors.py`).
- `scoping_run.json` — query strings, hit counts, and per-anchor recall for a dated run (`analysis/02_scoping.py`).

## `scoping_run.json`
| Field | Meaning |
|---|---|
| `run_date` | Date the queries were executed against PubMed |
| `queries` | Exact query string per family, as submitted |
| `counts` | Hit count per family and for the union |
| `anchors[]` | `key`, `pmid`, `category`, `recall_test`, `retrieved_by[]`, `retrieved` |
| `recall` | Proportion of testable anchors retrieved by at least one family |

`recall_test = false` marks anchors that PLAN §6.3 would exclude at screening anyway
(opinion without original data, method/tool papers, individual trial reports). They are
retained for provenance but excluded from the Phase 1 gate.

## Query families
| Family | Purpose | Feeds |
|---|---|---|
| `arm1_efficacy` | Efficacy concordance, induced/engineered models | Arm 1 |
| `arm2_safety` | Safety pharmacology and human adverse events | Arm 2 |
| `arm3_tox` | Toxicology concordance | Arm 3 |
| `arm4_vet` | Spontaneous disease in client-owned animals | Arm 4 |
| `aux_bias` | Preclinical reproducibility and publication bias | SQ5 |
| `aux_attrition` | Clinical development success rates | PPV base rate (§7.2) |

Auxiliary families are **not** concordance measurements. They supply the bias adjustment
and the prevalence axis of the PPV curve, and are never pooled with arm estimates.
