| `concordan*`[tiab] | 108,835 | genetic/twin concordance |
| `Translational Research, Biomedical`[Mesh] | 15,440 | (on-topic; the only precise one) |

There is no MeSH descriptor meaning "measures animal-to-human concordance", and the
landmark papers share no vocabulary — titles include *Are animal models as good as we
think?*, *Lost in translation*, and *Believe it or not…*. Any string tight enough to be
precise keys on phrasing most target papers do not use.

## Declared limitation — anchor-set overfitting

The anchor set was assembled from prior knowledge and then used to guide query
revision, so query recall measured on it is optimistic by construction and says
nothing about papers nobody thought to name. Citation recall is measured
leave-one-out and does not depend on the tuned vocabulary, so it is the less
contaminated of the two estimates. A held-out check against reference lists of
published reviews remains required before Phase 2 closes.
